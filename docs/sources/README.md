# Sources

- `plan-comptable-agricole-2015.pdf`: the Plan Comptable Agricole (CNC, avis n° 7 du 22 décembre 2015), from finances.gov.ma.
- `cgnc-tome-I-p250-340.ocr.txt`: OCR of pages 250–340 of the scan of the Code Général de la Normalisation Comptable, Tome I (CNC). Pages 250–315 are the normal model's "Cadre comptable et plan de comptes", pages 316–339 the simplified model's. The scan is linked as "Code Général de la Normalisation Comptable : TOME I et TOME II" from the CNC standards page of finances.gov.ma; it is 626 image-only pages and is not kept in the repository.
  - Made with Tesseract 5.4 (`fra`). The text has no page markers and contains OCR errors (dropped or misread digits, for example 7385 read as "1385"). Check a number against the page image before relying on its absence.
